# 每日盤前彙整流程

入口：`python3 scripts/daily_brief.py --scheduled`。固定以 `Asia/Taipei` 決定資料日期。手動無需交易日檢查時可省略 `--scheduled`，頁面「更新盤勢」也是相同擷取程式。

1. 即時讀取 TWSE 當年度開休市日曆。週末、國定休市與僅交割日跳過；日曆無法核實時記錄 `blocked`，不產生假日報。年度日曆不涵蓋臨時停市；須參照當日公告。
2. 擷取 TWSE 前次台股加權／台積電已收盤資料；擷取 Yahoo Finance 前次完整美股交易日的 S&P 500／Nasdaq／Dow／SOX。排除未結束的日 K，不把盤中數值標為收盤。
3. 擷取 FRED 美國 10 年債殖利率與紐約 Fed EFFR。記錄各自觀測日期，不把利率變動當股價漲跌，殖利率變動用百分點。
4. 讀取 BLS／BEA 官方排程，換算台北時間，涵蓋非農／CPI／PPI／PCE／GDP 等機構發布項目。再讀 Fed FOMC 會議日期與已發布演說 RSS。排序先今日、再重要性；缺發布時刻、預期、前值、實際值時保留 `null` 與說明。尚未完整涵蓋的 ISM、初領、零售、台灣出口、央行、外資、國際事件另列缺漏，不宣稱「今天沒有事件」。
5. 以 Apple lookup 核實 Podcast ID，讀取 SoundOn RSS 的最新已發布集數。只依據標題／原始簡介，不假裝聽過內容。Spotify 線索無法核實即保留待更新；App 會員看板與 Threads 讀不到就明說。
6. 有 `ANTHROPIC_API_KEY` 才將已擷取來源交給模型做當日人物推演與摘要。API 本身不具備此流程的上網能力，上網由前述擷取器負責。8 人依各自公開框架，不冒充本人、不強迫意見分歧。無金鑰時立場留 `null`，保留框架說明。
7. 驗證必要欄位後以原子寫入保存 `data/briefs/YYYY-MM-DD.json`，並更新 `data/last-run.json`。不得改動庫存。失敗則回報原因；若寫入失敗，在標準輸出保留完整已生成 JSON 供人工保存。
8. 如使用 `--notify`，嘗試本機通知；不支援則保留網頁與 JSON。Codex 自動化會在新交易日日報完成、失敗或需要處理時通知；正常休市與無變更時保持安靜。

預定時刻：週一至五 07:52。已啟用的 Codex 自動化可從卡片改時間、停用。主機與 Codex 必須可執行；尚未驗證未來自動喚醒。
